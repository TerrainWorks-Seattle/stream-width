# Stream width models

Scripts and notebooks related to stream width and classification. 

# Contents

## [Channel geometry from a DEM](channel_width_from_DEM.md) 
Describes an algorithm for deriving channel geometry from a DEM. 

## [Linear ordinal regression model](linear_model.md)
Fits an ordinal regression model to a small dataset and evaluates it 
for spatial autocorrelation. 

## [Model description](stream_width_gamma.qmd)
Describes a model for estimating stream width using gamma regression, including 
variations which account for spatial autocorrelation and can incorporate 
multiple different types of observations. 

## [Stream width literature](stream_width_literature.md)
Brief summary of some recent literature around predicting channel geometry. 

## [Spatial models](stream_width_spatial.md)
Fits a few variations of spatial models for predicting stream width.
